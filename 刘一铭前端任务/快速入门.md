# 🚀 快速入门指南

## 5分钟上手 DiffProtect Pro 前端

### 第一步：启动后端（必需）

确保后端服务已在 `http://localhost:8000` 运行。

检查后端是否正常：
```bash
curl http://localhost:8000/api/health
```

应返回类似：
```json
{
  "status": "ok",
  "version": "0.5.0",
  "device": "cuda"
}
```

### 第二步：启动前端

**方式 A：直接打开（推荐，最简单）**
```bash
# 直接用浏览器打开
双击 index.html
```

**方式 B：使用本地服务器（避免CORS）**
```bash
# Windows
双击 start.bat

# Mac/Linux
chmod +x start.sh
./start.sh

# 或手动启动
python -m http.server 8080
```

然后访问：http://localhost:8080

### 第三步：体验功能

#### 1️⃣ 人脸验证（无需登录）⭐核心功能

1. 点击顶部菜单 **"人脸验证"**
2. 上传两张人脸照片（照片A和照片B）
3. 选择要使用的FR模型（默认全选4个）
4. 点击 **"开始验证"**
5. 查看结果：
   - 每个模型的相似度和判定
   - 综合结论（多数投票）
   - 处理耗时

**答辩演示重点：**
- 展示保护前后的两张照片对比
- 说明4个不同FR模型的识别结果
- 解释综合判定规则（3/4投票）

#### 2️⃣ 注册账号

1. 点击 **"注册"**
2. 填写信息：
   - 手机号：11位（例如：13800138000）
   - 昵称：2-20字符
   - 密码：6位以上
3. 点击 **"注册"**
4. 自动登录并跳转到动态流

#### 3️⃣ 浏览动态（需登录）

1. 登录后自动进入 **"动态"** 页面
2. 浏览所有用户发布的帖子
3. 查看帖子的保护状态标识
4. 点击❤️图标进行点赞（可取消）
5. 点击💬图标会提示"Demo版暂不支持评论"

#### 4️⃣ 发布动态（需登录）

1. 点击 **"发布动态"** 按钮
2. 填写文字内容（可选）
3. 上传图片（最多9张）或视频
4. 选择是否启用保护：
   - ✅ 启用 DiffProtect 保护
   - 选择保护强度（Level 1-3）
   - 可选：选择性保护（仅保护指定人脸）
5. 点击 **"发布"**

#### 5️⃣ 配置设置（需登录）

1. 点击 **"设置"**
2. 配置默认保护参数：
   - 默认保护强度
   - 是否默认启用选择性保护
   - 默认保护的人脸索引
3. 点击 **"保存设置"**

## ⚠️ 常见问题

### Q1: 点击验证后没有反应？
**A:** 检查：
1. 后端是否启动（访问 http://localhost:8000/api/health）
2. 浏览器控制台是否有CORS错误
3. 两张照片是否都已上传

### Q2: 登录失败？
**A:** 确认：
1. 手机号格式正确（11位）
2. 如果是新用户，先注册
3. 后端数据库已初始化

### Q3: 发布动态时提示网络错误？
**A:** 检查：
1. 是否已登录
2. Token是否有效
3. 后端上传目录权限
4. 图片/视频大小是否过大

### Q4: 看不到已发布的动态？
**A:** 
1. 刷新页面重新加载
2. 检查后端数据库是否保存成功
3. 查看浏览器控制台错误信息

### Q5: 页面样式错乱？
**A:** 
1. 确保 styles.css 文件存在
2. 检查浏览器是否支持现代CSS特性
3. 清除浏览器缓存后重试
