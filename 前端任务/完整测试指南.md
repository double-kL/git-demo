## 🎯 立即开始测试

### 方法一：使用Mock后端（推荐，最完整）

#### 第1步：启动Mock后端

**Windows:**
```bash
双击 start-mock-server.bat
```

**Mac/Linux:**
```bash
chmod +x start-mock-server.sh
./start-mock-server.sh
```

**或手动启动:**
```bash
npm install      # 首次运行
npm start        # 启动服务器
```

✅ **看到这个说明启动成功:**
