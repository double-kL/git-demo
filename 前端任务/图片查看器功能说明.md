# 🖼️ 图片查看器功能说明

## 功能介绍

全新的图片查看器功能已完成！类似相册浏览器，支持：
- ✅ 点击图片放大查看
- ✅ 左右切换查看多张图片
- ✅ 缩放功能（50% - 300%）
- ✅ 图片计数显示
- ✅ 流畅的过渡动画
- ✅ 键盘快捷键支持

---

## 🎯 使用方法

### 1. 打开图片查看器

**方式1：点击普通图片**
- 在动态流中点击任意普通图片
- 图片查看器自动打开
- 显示点击的图片

**方式2：点击多图中的某张**
- 如果帖子有多张图片
- 点击任意一张
- 查看器打开并显示该图片
- 可以左右切换查看其他图片

### 2. 切换图片

**方式1：点击左右按钮**
- 左箭头 ‹ : 上一张
- 右箭头 › : 下一张
- 首尾图片时按钮禁用

**方式2：键盘快捷键**（可扩展）
- 左箭头键: 上一张
- 右箭头键: 下一张
- Esc键: 关闭查看器

### 3. 缩放图片

**底部工具栏：**
- **− 按钮**: 缩小（最小50%）
- **+ 按钮**: 放大（最大300%）
- **重置按钮**: 恢复100%
- **百分比显示**: 当前缩放比例

**鼠标滚轮**（可扩展）：
- 向上滚动: 放大
- 向下滚动: 缩小

### 4. 关闭查看器

**方式1：点击关闭按钮**
- 右上角的 ✕ 按钮

**方式2：点击背景**
- 点击图片外的黑色背景

**方式3：按Esc键**（可扩展）
- 按键盘Esc键

## 🎮 交互细节

### 按钮状态

| 按钮 | 状态 | 说明 |
|------|------|------|
| ‹ 上一张 | 启用 | 不是第一张时可点击 |
| ‹ 上一张 | 禁用 | 已经是第一张（灰色） |
| › 下一张 | 启用 | 不是最后一张时可点击 |
| › 下一张 | 禁用 | 已经是最后一张（灰色） |
| − 缩小 | 禁用 | 已经是50%（灰色） |
| + 放大 | 禁用 | 已经是300%（灰色） |

### 缩放级别

```
50% → 75% → 100% → 125% → 150% → 175% → 200% → 225% → 250% → 275% → 300%
      ←0.25→   ←0.25→   ←0.25→   ←0.25→   ←0.25→   ←0.25→   ←0.25→
```

每次点击 +/− 按钮，缩放 ±25%

## 📊 数据结构

### 前端状态

```javascript
imageViewer: {
    show: false,              // 是否显示查看器
    images: [],               // 图片URL数组
    currentIndex: 0,          // 当前显示的图片索引
    scale: 1                  // 缩放比例（1 = 100%）
}
```

### 示例用法

```javascript
// 打开查看器
openImageViewer(images, index = 0) {
    this.imageViewer = {
        show: true,
        images: images,           // ['url1', 'url2', 'url3']
        currentIndex: index,      // 0
        scale: 1
    };
    document.body.style.overflow = 'hidden'; // 禁止滚动
}

// 关闭查看器
closeImageViewer() {
    this.imageViewer = {
        show: false,
        images: [],
        currentIndex: 0,
        scale: 1
    };
    document.body.style.overflow = ''; // 恢复滚动
}
```

## 🔧 技术实现

### 核心代码

```javascript
// 打开查看器
openImageViewer(images, index = 0) {
    this.imageViewer = {
        show: true,
        images: images,
        currentIndex: index,
        scale: 1
    };
    document.body.style.overflow = 'hidden';
}

// 切换图片
nextImage() {
    if (this.imageViewer.currentIndex < this.imageViewer.images.length - 1) {
        this.imageViewer.currentIndex++;
        this.imageViewer.scale = 1; // 重置缩放
    }
}

// 缩放
zoomIn() {
    if (this.imageViewer.scale < 3) {
        this.imageViewer.scale += 0.25;
    }
}
```

### CSS关键样式

```css
.image-viewer-image img {
    max-width: 100%;
    max-height: 85vh;
    object-fit: contain;          /* 完整显示 */
    transition: transform 0.3s;
    transform: scale(var(--scale)); /* 缩放 */
}
```
