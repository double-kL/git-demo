# 🖱️ 图片拖动功能说明

## 功能介绍

图片查看器现在支持**拖动功能**！放大后可以移动图片查看不同区域。

---

## ✨ 新增功能

### 1. **图片拖动** 🖱️
- ✅ 放大后可以拖动图片
- ✅ 查看被裁剪的不同区域
- ✅ 鼠标指针自动变化（grab/grabbing）
- ✅ 流畅的拖动体验

### 2. **智能限制**
- ✅ 只有放大后（>100%）才能拖动
- ✅ 100%及以下自动禁用拖动
- ✅ 切换图片时自动重置位置
- ✅ 缩小到100%时自动归位

---

## 🎯 使用方法

### 第1步：打开图片查看器
- 点击动态流中的任意普通图片
- 查看器全屏打开

### 第2步：放大图片
- 点击底部工具栏的 **+** 按钮
- 图片放大到 **125%、150%、200%** 等

### 第3步：拖动图片
1. **鼠标指针变成手型** 👋（表示可以拖动）
2. **按住鼠标左键** 在图片上
3. **拖动鼠标** 移动图片
4. **松开鼠标** 停止拖动

### 示例操作流程
```
1. 点击图片 → 查看器打开
2. 点击 + → 放大到150%
3. 鼠标变成手型 👋
4. 按住并拖动 → 查看不同区域
5. 点击 − 或"重置" → 图片归位
```

## 🔧 技术实现

### 数据结构
```javascript
imageViewer: {
    scale: 1.5,           // 缩放比例（150%）
    translateX: -100,     // X轴偏移（拖动距离）
    translateY: 50,       // Y轴偏移
    isDragging: false,    // 是否正在拖动
    dragStartX: 0,        // 拖动起始X坐标
    dragStartY: 0         // 拖动起始Y坐标
}
```

### 核心代码
```javascript
// 开始拖动
startDrag(event) {
    if (this.imageViewer.scale > 1) {  // 只有放大后才能拖
        this.imageViewer.isDragging = true;
        this.imageViewer.dragStartX = event.clientX - this.imageViewer.translateX;
        this.imageViewer.dragStartY = event.clientY - this.imageViewer.translateY;
    }
}

// 拖动中
onDrag(event) {
    if (this.imageViewer.isDragging) {
        this.imageViewer.translateX = event.clientX - this.imageViewer.dragStartX;
        this.imageViewer.translateY = event.clientY - this.imageViewer.dragStartY;
    }
}

// 停止拖动
stopDrag() {
    this.imageViewer.isDragging = false;
}
```

### CSS样式
```css
.image-viewer-image img {
    /* 快速响应的过渡效果 */
    transition: transform 0.1s ease-out;
    
    /* 禁止选中图片 */
    user-select: none;
    
    /* 动态鼠标指针 */
    cursor: grab; /* 或 grabbing */
}
```

## ⚙️ 技术细节

### Transform计算
```javascript
// CSS transform同时应用缩放和位移
transform: `scale(${scale}) translate(${translateX / scale}px, ${translateY / scale}px)`

// 除以scale是为了补偿缩放对位移的影响
// 例如：scale=2时，移动50px实际需要translate(25px)
```

### 事件监听
```html
<div @mousedown="startDrag"      <!-- 按下鼠标 -->
     @mousemove="onDrag"         <!-- 移动鼠标 -->
     @mouseup="stopDrag"         <!-- 松开鼠标 -->
     @mouseleave="stopDrag">     <!-- 鼠标离开区域 -->
```

### 防止默认行为
```javascript
@mousedown.prevent  // 防止图片被拖拽选中
event.preventDefault()  // 防止文本选择
```
