# 📸 动态照片功能说明

## 功能介绍

动态照片功能类似于**微信朋友圈的动态照片**，由**1张静态图片 + 1个短视频**组成。

- 默认显示静态图片
- 图片上显示"⚡ 动态"标识
- 点击图片或"动态"按钮播放视频
- 视频播放完毕自动返回显示图片

---

## 如何使用动态照片

### 1️⃣ 发布动态照片

1. **登录账号**（必须登录）
2. **进入发布页**：点击导航栏"动态" → "发布动态"
3. **找到"上传动态照片"区域**
4. **点击"+ 动态照片"按钮**
5. **选择文件**：
   - 方式1：先选1张图片，再选1个视频
   - 方式2：同时选择图片和视频（Ctrl多选）
6. **完成**：会在预览中看到带"动态"标识的图片

> 💡 **提示**：
> - 动态照片和普通图片共用9张的限制
> - 可以同时上传多个动态照片
> - 每个动态照片 = 1图 + 1视频

---

### 2️⃣ 查看动态照片

在动态流中：

1. **识别动态照片**：右上角有 **"⚡ 动态"** 按钮
2. **播放方式**：
   - 点击图片
   - 或点击"⚡ 动态"按钮
3. **查看器打开**：
   - 显示大图
   - 底部有"▶ 播放动态照片"按钮
4. **播放视频**：点击播放按钮
5. **自动返回**：视频播放完毕自动回到图片
6. **关闭查看器**：点击右上角 ✕ 或点击背景

## 技术实现

### 前端结构

```javascript
// 数据结构
newPost.livePhotos = [
    {
        imageFile: File,        // 图片文件
        videoFile: File,        // 视频文件
        imagePreview: String,   // 图片预览URL
        videoPreview: String    // 视频预览URL
    }
]

// 帖子数据
post = {
    images: ['url1', 'url2'],           // 所有图片URL
    live_videos: {                       // 动态照片视频映射
        0: 'video_url',                  // 第0张图片的视频
        2: 'video_url'                   // 第2张图片的视频
    },
    video: 'url'                         // 独立视频（可选）
}
```

### 后端接口

发布动态时：
```
POST /api/posts

FormData:
- images: [图片文件...]
- live_videos: [动态照片的视频文件...]
- live_photo_indices: "[0, 2]"  // JSON字符串，标记哪些图片有视频
- video: 独立视频文件（可选）
```

## 常见问题

### Q1: 为什么我的动态照片没有显示"⚡ 动态"标识？

**A:** 检查以下几点：
1. 是否同时上传了图片和视频
2. 后端是否正确返回了 `live_videos` 数据
3. 浏览器控制台是否有错误

### Q2: 点击图片没有打开查看器？

**A:** 只有带 `live_videos` 的图片才能打开查看器，普通图片点击无效果。

### Q3: 视频播放不了？

**A:** 检查：
1. 视频格式是否支持（推荐mp4）
2. 视频URL是否有效
3. 浏览器控制台网络请求是否成功

### Q4: 动态照片和普通视频有什么区别？

**A:**
- **动态照片**：图片 + 视频，默认显示图片，点击播放视频
- **普通视频**：独立的视频，直接显示在动态中
