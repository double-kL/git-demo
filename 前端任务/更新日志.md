## 📊 数据结构

### 前端数据结构

```javascript
// 发布时
newPost = {
    content: '文字内容',
    images: [File, File],              // 普通图片文件
    livePhotos: [                      // 动态照片数组
        {
            imageFile: File,           // 图片文件
            videoFile: File,           // 视频文件
            imagePreview: 'data:...',  // 图片预览URL
            videoPreview: 'data:...'   // 视频预览URL
        }
    ],
    video: File                        // 独立视频文件
}

// 显示时
post = {
    images: ['url1', 'url2', 'url3'],  // 所有图片URL
    live_videos: {                      // 动态照片视频映射
        0: 'video_url',                 // 第0张图片的视频
        2: 'video_url'                  // 第2张图片的视频
    },
    video: 'video_url'                  // 独立视频（可选）
}
```

### 后端接口格式

```
POST /api/posts

FormData:
├─ content: 文字内容
├─ images: [普通图片文件...]
├─ live_videos: [动态照片的视频文件...]
├─ live_photo_indices: "[0, 2]"  // JSON字符串
└─ video: 独立视频文件（可选）

Response:
{
    status: "ok",
    post: {
        id: "p_123",
        images: ["url1", "url2", "url3"],
        live_videos: {
            0: "video_url",
            2: "video_url"
        },
        video: "video_url",
        ...
    }
}
```

## 🎯 使用流程

### 发布动态照片

```
1. 登录 → 2. 点击"动态" → 3. 点击"发布动态"
                                    ↓
4. 找到"上传动态照片"区域 → 5. 点击"+ 动态照片"
                                    ↓
6. 选择1图 + 1视频 → 7. 看到预览（带"动态"标识）
                                    ↓
8. 填写内容 → 9. 点击"发布" → 10. 完成
```

### 查看动态照片

```
1. 进入动态流 → 2. 识别"⚡ 动态"标识
                            ↓
3. 点击图片或按钮 → 4. 查看器打开（显示图片）
                            ↓
5. 点击播放按钮 → 6. 视频播放
                            ↓
7. 播放完毕 → 8. 自动返回显示图片
                            ↓
9. 点击✕或背景关闭
```

## ⚠️ 注意事项

### 1. 必须重启后端
修改了 `mock-server.js`，必须重启后端服务器才能生效！

### 2. 清除旧数据
旧的Token可能导致问题，建议清除LocalStorage。

### 3. 文件选择
上传动态照片时，需要同时选择图片和视频：
- 方式1：先选图片，弹窗关闭，再点一次选视频
- 方式2：按住Ctrl同时选择多个文件

### 4. 浏览器兼容性
推荐使用Chrome或Edge浏览器，视频格式建议MP4。
