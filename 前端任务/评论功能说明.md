## 🎯 使用方法

### 1. 查看评论

**在动态流中：**
1. 找到任意帖子
2. 点击 💬 评论按钮（显示评论数量）
3. 评论区展开，显示评论列表

**评论列表显示：**
- 用户头像（昵称首字母）
- 用户昵称
- 评论内容
- 发布时间（相对时间）

### 2. 发表评论

**方式1：点击发送按钮**
1. 在评论输入框中输入内容
2. 点击"发送"按钮
3. 评论立即显示在列表中

**方式2：回车快捷键**
1. 在评论输入框中输入内容
2. 按 Enter 键
3. 评论立即发送

### 3. 折叠评论区

再次点击 💬 评论按钮即可折叠评论区

## 📝 代码实现

### 前端核心代码

```javascript
// 切换评论区
toggleComments(post) {
    post.showComments = !post.showComments;
    if (post.showComments && !post.comments) {
        this.$set(post, 'comments', []);
        this.$set(post, 'newComment', '');
    }
},

// 提交评论
async submitComment(post) {
    if (!post.newComment || !post.newComment.trim()) {
        return;
    }
    
    const response = await fetch(
        `${this.apiBaseUrl}/api/posts/${post.id}/comments`,
        {
            method: 'POST',
            headers: {
                ...this.authHeaders,
                'Content-Type': 'application/json'
            },
            body: JSON.stringify({
                content: post.newComment.trim()
            })
        }
    );
    
    const data = await response.json();
    
    if (response.ok && data.status === 'ok') {
        post.comments.push(data.comment);
        post.comments_count = (post.comments_count || 0) + 1;
        post.newComment = '';
        this.showToast('评论成功', 'success');
    }
}
```

### 后端核心代码

```javascript
// 发表评论接口
app.post('/api/posts/:postId/comments', (req, res) => {
    const user = verifyToken(req.headers.authorization);
    if (!user) {
        return res.status(401).json({ detail: "未登录" });
    }
    
    const post = posts.find(p => p.id === req.params.postId);
    if (!post) {
        return res.status(404).json({ detail: "帖子不存在" });
    }
    
    const { content } = req.body;
    if (!content || !content.trim()) {
        return res.status(400).json({ detail: "评论内容不能为空" });
    }
    
    const comment = {
        id: `c_${Date.now()}`,
        author: {
            id: user.id,
            nickname: user.nickname,
            avatar: null
        },
        content: content.trim(),
        created_at: new Date().toISOString()
    };
    
    if (!post.comments) {
        post.comments = [];
    }
    post.comments.push(comment);
    post.comments_count = post.comments.length;
    
    res.json({ status: "ok", comment });
});
```
