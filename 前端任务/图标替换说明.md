## 🎯 如何自定义图标

### 方法1：使用阿里图标库（推荐）

#### 第1步：访问阿里图标库
```
https://www.iconfont.cn/
```

#### 第2步：注册并登录
- 使用微博/GitHub/手机号注册
- 登录账号

#### 第3步：搜索并选择图标
1. 在搜索框输入关键词（例如：盾牌、闪电、心形）
2. 选择喜欢的图标
3. 点击"加入购物车"

**推荐搜索关键词：**
- 盾牌：shield、安全
- 闪电：flash、lightning、快速
- 动态：dynamic、手机、mobile
- 编辑：edit、写作、笔
- 设置：setting、齿轮
- 相机：camera、照相
- 心形：heart、喜欢、like
- 评论：comment、消息、chat
- 播放：play、播放器

#### 第4步：创建项目
1. 点击右上角购物车图标
2. 点击"添加至项目"
3. 创建新项目或选择现有项目
4. 输入项目名称，例如"DiffProtect图标"

#### 第5步：生成代码
1. 进入"我的项目"
2. 找到刚创建的项目
3. 点击"Font class"
4. 点击"生成代码"
5. 复制生成的链接

**生成的链接示例：**
```html
<link rel="stylesheet" href="//at.alicdn.com/t/c/font_1234567_abcdefg.css">
```

#### 第6步：替换链接
在 `index.html` 中替换：
```html
<!-- 将这行 -->
<link rel="stylesheet" href="https://at.alicdn.com/t/c/font_4701800_ijpo743bc1.css">

<!-- 替换为你自己的链接 -->
<link rel="stylesheet" href="//at.alicdn.com/t/c/font_你的项目ID_你的代码.css">
```

#### 第7步：查看图标类名
1. 在项目页面，每个图标下方显示类名
2. 例如：`icon-shield`、`icon-heart`
3. 如果类名不同，需要修改HTML中的类名

## 🔄 如何修改图标

### 示例：替换心形图标

**原始代码：**
```html
<i class="iconfont icon-heart"></i>
```

**如果你选择的心形图标类名是 `icon-love`：**
```html
<i class="iconfont icon-love"></i>
```

### 需要修改的位置

在 `index.html` 中搜索并替换：

| 位置 | 搜索 | 替换为你的类名 |
|-----|------|--------------|
| 点赞按钮 | `icon-heart` | `icon-你的类名` |
| 点赞按钮（已点赞）| `icon-heart-fill` | `icon-你的类名-fill` |
| 盾牌 | `icon-shield` | `icon-你的类名` |
| 闪电 | `icon-flash` | `icon-你的类名` |
| ...等等 | ... | ... |

## 🎨 图标样式调整

### 修改图标大小
在 `styles.css` 中调整：

```css
/* 标题图标 */
h1 .iconfont {
    font-size: 1.5em;  /* 改为更大 */
}

/* 按钮图标 */
.action-btn .icon .iconfont {
    font-size: 1.5rem;  /* 改为更大 */
}
```

### 修改图标颜色
```css
/* 盾牌图标 */
.icon-shield {
    color: #6b7280;  /* 灰色 */
}

/* 闪电图标 */
.icon-flash {
    color: #f59e0b;  /* 黄色 */
}

/* 点赞图标（已点赞）*/
.icon-heart-fill {
    color: #ef4444;  /* 红色 */
}
```

### 修改图标间距
```css
/* 图标和文字之间的间距 */
h2 .iconfont {
    margin-right: 0.5rem;  /* 增加间距 */
}
```

## ⚠️ 常见问题

### Q1: 图标显示为方框？

**原因：** 图标库链接失效或图标类名不匹配

**解决：**
1. 检查图标库链接是否正确
2. 确认图标类名是否匹配
3. 检查网络是否能访问阿里图标库

### Q2: 图标太大或太小？

**解决：** 在CSS中调整 `font-size`
```css
.iconfont {
    font-size: 1.2em;  /* 调整大小 */
}
```

### Q3: 图标和文字不对齐？

**解决：** 调整 `vertical-align`
```css
.iconfont {
    vertical-align: middle;  /* 垂直居中 */
}
```

### Q4: 想要更换图标？

**解决：**
1. 去阿里图标库选择新图标
2. 加入项目并更新代码
3. 替换HTML中的类名

## 📝 优势对比

### Emoji的问题
- ❌ 不同平台显示效果不一致
- ❌ 无法精确控制大小和颜色
- ❌ 可能显示为黑白或彩色（不可控）
- ❌ 行高问题导致排版不美观

### 字体图标的优势
- ✅ 跨平台显示一致
- ✅ 可以像文字一样调整大小
- ✅ 可以自由控制颜色
- ✅ 矢量图形，任意缩放不失真
- ✅ 加载速度快
- ✅ 易于维护和替换
