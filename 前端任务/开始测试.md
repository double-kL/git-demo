## 📝 快速测试流程

### 1️⃣ 测试人脸验证（无需登录）
```
打开页面 → 点击"人脸验证" → 上传两张图片 → 开始验证 → 查看结果
```

### 2️⃣ 测试登录保护
```
不登录 → 尝试点击"动态"或"设置" → 应该看不到这些菜单
登录后 → 菜单变为"动态"、"设置"、"退出"
```

### 3️⃣ 测试发布动态
```
登录 → 点击"发布动态" → 输入内容 → 上传图片 → 启用保护 → 发布
```

### 4️⃣ 测试点赞
```
在动态流 → 点击❤️图标 → 点赞数+1 → 再点击 → 取消点赞
```

详细测试步骤请查看：[完整测试指南.md](完整测试指南.md)
