# DiffProtect Pro 前端项目 - 完整说明

## 📋 项目概述

这是一个基于 **Vue 3** 开发的单页应用（SPA），实现了 DiffProtect Pro 人脸隐私保护平台的完整前端功能。

**技术栈：**
- Vue 3 (CDN方式，无需构建工具)
- 原生 Fetch API
- 纯 CSS（无UI框架）
- LocalStorage 状态持久化

## 🚀 部署方式

### 方式1：直接使用（最简单）
```bash
# 直接用浏览器打开
双击 index.html
```

**优点：** 无需任何工具，即开即用  
**限制：** 可能遇到CORS问题

### 方式2：本地服务器
```bash
# Windows
双击 start.bat

# Linux/Mac
chmod +x start.sh && ./start.sh

# 手动启动
python -m http.server 8080
```

访问：http://localhost:8080

**优点：** 避免CORS问题  
**推荐：** 开发和演示使用

### 方式3：打包单文件
```bash
# 使用Node.js运行打包脚本
node build.js

# 输出：dist.html（单文件，所有资源内联）
```

**优点：** 一个文件包含所有内容，方便分享  
**用途：** 最终交付或演示

### 方式4：生产部署
1. 上传文件到Web服务器（Nginx/Apache）
2. 修改 `app.js` 中的 `apiBaseUrl` 为生产地址
3. 配置CORS允许前端域名

## 🔧 配置修改

### 修改后端地址

**app.js 第6行：**
```javascript
apiBaseUrl: 'http://localhost:8000',  // 改为你的后端地址
```

### 修改分页数量

**app.js 第54行：**
```javascript
page_size: 10,  // 每页显示数量
```

### 修改Toast持续时间

**app.js 第107行：**
```javascript
setTimeout(() => {
    this.toast.show = false;
}, 3000);  // 3000毫秒 = 3秒
```
